# RAG 评测报告（S4.5）

## 语料

| 项 | 数量 |
|---|---|
| 平台已发布文档 | 20 |
| 其中：示例真实文档 | 2（内部采购管理制度、供应商准入与绩效评价管理办法） |
| 其中：评测语料 | 18（覆盖需求、计划、招标、谈判、询价、单一来源、合同、履约、验收、退货、仓储、盘点、绩效、退出、价格、预算、档案、廉洁） |
| Qdrant 切片 | 23 |
| 向量模型 | bge-m3（1024 维，本地 CPU） |

## 评测集

- **45 个可回答问题**：36 个来自 18 份评测文档（每份 2 问）+ 6 个针对 2 份真实文档 + 3 个跨文档问题；
- **5 个无关问题**：天气、写诗、NBA、编程学习、附近餐厅；
- 判定：Top5 命中（期望文档出现在前 5 条）、关键词命中、无关问题返回 0 条。

## 结果

| 指标 | 结果 |
|---|---|
| Top1 命中率 | 39/45 = **86.7%** |
| Top5 命中率 | 45/45 = **100%** |
| 关键词命中率 | 45/45 = **100%** |
| 无关问题拒答率 | 5/5 = **100%** |

- `KB_MIN_SCORE=0.40` 是在本语料上实测得到的拒答阈值：无关问题最高分 0.397，相关问题最低分 0.562，阈值取 0.40 可同时满足召回与拒答。
- 复现命令：`conda run -n procurement python scripts/eval_rag.py`（需要 Qdrant 与已入库文档）。

## 已知限制

- Top1 仍有 6 条被相邻主题文档占据（如“预算/计划”“合同/履约”），Top5 内可纠正；
- 每份评测文档约 600 字，通常只切出 1 个切片，未验证长文档的跨切片召回；
- 未接 rerank 模型，阈值是静态的；语料扩充后需重新标定；
- 扫描件 PDF 未做 OCR，表格按纯文本抽取。
